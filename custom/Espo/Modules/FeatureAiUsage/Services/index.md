# AI usage services

- `Access.php` — selected-tenant administrator authorization.
- `Period.php` — bounded calendar-month windows and equivalent-period comparisons.
- `Ledger.php` — billing-grain prices and monthly allowance reconciliation.
- `Dataset.php` — action, record, agent, and daily consumption read models.
- `Projection.php` — ACL-aware record labels and detail links.
- `Analytics.php` — admin-only consumption, cache, request, source and duration metrics; see [accounting semantics](analytics.md).
- `Service.php` — public API orchestration and bounded database access.
